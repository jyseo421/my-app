# 신모델 개발일정 관리 시스템

신모델 개발일정을 관리하는 담당자(PM/일정 담당자)가 50개 이상의 모델을 대상으로,
사양그룹·출향지·법인 조건에 따라 달라지는 소요 시간을 반영해 개발 순서와 일정을
**자동으로 계산**해주는 사내 업무 시스템입니다.

기존에는 담당자가 엑셀로 모델별 조건을 일일이 대조하며 손으로 일정을 짰습니다.
모델 수가 많아질수록 병렬/직렬 진행 여부, 신뢰성 시험 소요 시간, 규격취득 조건,
법인별 주간 Capa까지 동시에 고려해야 해서 계산 누락과 오류가 발생하기 쉬웠고,
조건이 하나라도 바뀌면 전체 일정을 처음부터 다시 계산해야 했습니다. 이 시스템은
그 과정을 자동화합니다.

> 이 저장소에는 애플리케이션 소스 코드만 포함되어 있으며, 실제 모델·일정 데이터는
> 포함하지 않습니다. 데이터는 별도의 Supabase 프로젝트에 저장되고, 화면 접근은
> 단일 비밀번호로 통제됩니다.

## 핵심 기능

- **자동 일정 수립**: 사양그룹별 병렬/직렬 설정에 따른 기구개발·성능개발, 신뢰성
  시험(기본 병렬, 일부 직렬), 규격취득(신뢰성 시험과 항상 병렬)을 반영해 전체 모델의
  개발 순서와 일정을 한 번에 계산합니다. 법인별 주간 Capa를 초과하지 않도록 사양그룹
  → 출향지 우선순위 순으로 배치합니다.
- **모델·마스터 정보 관리**: 법인, 사양그룹, 신뢰성 시험, 규격 마스터 테이블과 모델
  정보를 화면에서 등록·관리합니다. 엑셀 붙여넣기(Ctrl+V)와 파일 첨부로 일괄 입력할
  수 있고, 필수 항목 누락·중복 시험 항목 등록 시 자동으로 막습니다.
- **일정 재계산·비교**: 조건이 바뀌면 전체 일정을 다시 계산하고, 이전 일정과 최신
  일정을 나란히 비교하며 변경된 부분을 색으로 표시합니다.
- **엑셀 내보내기**: 일정 결과, 모델 정보, 마스터 테이블을 언제든 엑셀 파일로
  내려받을 수 있습니다.
- **단일 비밀번호 접근 통제**: 별도 로그인 계정 없이 단일 비밀번호로 접근을
  통제하며, 비밀번호는 화면에서 직접 변경할 수 있습니다.

## 기술 스택

| 영역 | 기술 |
|---|---|
| 프론트엔드 · 서버 | [Next.js](https://nextjs.org) (App Router, TypeScript, Tailwind CSS) |
| 데이터베이스 | [Supabase](https://supabase.com) (PostgreSQL, RLS 적용) |
| 인증 | 단일 비밀번호 게이트 (bcryptjs 해시, HMAC 서명 세션) |
| 일정 계산 | date-fns, date-holidays(한국 공휴일 반영) |
| 엑셀 입출력 | SheetJS(xlsx) |
| 배포 | [Vercel](https://vercel.com) |

## 로컬에서 실행하기

```bash
npm install
cp .env.example .env.local   # Supabase 등 환경 변수 값 채우기
npm run dev
```

`http://localhost:3000` 접속 후 처음 실행 시 화면에서 접근 비밀번호를 설정합니다.

### 환경 변수

| 변수명 | 설명 |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | Supabase 프로젝트 URL |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Supabase anon(공개) 키 |
| `SUPABASE_SERVICE_ROLE_KEY` | Supabase 서비스 롤 키 (서버 전용, 절대 공개 금지) |
| `SESSION_SECRET` | 접근 비밀번호 세션 서명용 비밀 키 |

값은 각자의 `.env.local` 파일에만 보관하며 저장소에 커밋하지 않습니다.

## 보안 · 데이터 등급

모델 사양·개발일정 정보는 사내 기밀(Confidential) 등급으로 취급하며 개인정보는
다루지 않습니다. 접근은 단일 비밀번호로 통제되고, 데이터베이스는 Row Level
Security로 잠겨 있어 서버 쪽 서비스 롤 키를 통해서만 접근할 수 있습니다.
